# PX4 Radiation Source Localization

A radiation source localization system built on the PX4 Autopilot framework, integrating a custom radiation detector module with Gazebo-based UAV simulation.

The system enables simulated radiation measurements, source localization, and visualization of radiation intensity distributions.

### Features
- Custom PX4 radiation detector module
- Simulated radiation measurements using a Gazebo plugin
- Integration with PX4 through a custom uORB message
- Radiation source localization based on collected measurements
- Heatmap generation and visualization
- Simulation using PX4 SITL and Gazebo

### Technologies
C++ · Python · PX4 Autopilot · Gazebo · CMake
